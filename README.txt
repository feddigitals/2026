# FED DIGITALS — Link page

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **Public** repository named `fed-digitals`.
2. Upload `index.html` and the `assets` folder (keep the folder structure).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then press **Save**.
6. After GitHub publishes it, your page will be available at:
   `https://YOUR-USERNAME.github.io/fed-digitals/`

Replace `YOUR-USERNAME` with your GitHub username.

## QR code
Create a QR code that points to the final GitHub Pages address above. The WhatsApp QR in the supplied screenshot is a direct WhatsApp contact QR, not the new link page QR.
